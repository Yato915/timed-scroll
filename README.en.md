# Timed Scroll

[中文](README.md)

A browser extension that scrolls the current page down on a fixed interval. Useful for long articles, documents, and feeds. Works in Edge and Chrome (Manifest V3).

## Features

- Custom scroll interval from 0.5 seconds to 60 minutes, entered in seconds or minutes
- Each step can be half a screen, one screen, or a custom pixel distance
- Smooth scrolling, and either stop at the bottom or return to the top and continue
- Mouse wheel, touch, or page keys pause scrolling for about 2.5 seconds
- A countdown orb in the bottom-right corner; drag to move it, hover to stop
- Shortcut `Alt+Shift+D` to start or stop

## Install

1. Clone this repository.
2. Open `edge://extensions` or `chrome://extensions`.
3. Turn on Developer mode.
4. Choose "Load unpacked" and select this repository directory.

## Development

Icons are generated by `scripts/generate_icons.py` with no third-party dependencies:

```bash
python scripts/generate_icons.py
```
